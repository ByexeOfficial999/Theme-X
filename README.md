_Bagaimana cara menginstal script ini di Termux Android Anda??. Lihat di bawah ini._

### INSTALL FOR TERMUX
```python
pkg update && pkg upgrade
pkg install python python-pip
pkg install git
pkg install make
git clone https://github.com/ByexeOfficial999/Theme-X
cd Theme-X
make install
make run
```

### ATASI ERROR
```python
cd && cd Theme-X
make fix
make run
```
